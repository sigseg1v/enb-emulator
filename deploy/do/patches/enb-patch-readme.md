# enb-patch.exe

Not included. Users need to provide this themselves, but this file explains what should be in it.

The way this code in this repo expects to be able to execute it is to call `enb-patch.exe "<path to EnB install folder>"`

## Exhaustive list of files in this patch (what each one is)

To play the game you need to start with the free `eandb_demo.exe` install (the
Earth & Beyond demo client). The demo install does **not** contain everything needed
for a fully working Freya EnB Emulator client. The files below are the additions/modifications this
patch layers on top of the demo install to produce a complete client. They are **not**
included in `eandb_demo.exe`; you can obtain them from a retail Earth & Beyond install
or from other hosted emulators/servers.

Notation: `ADD` = new file not present in the demo; `PATCH` = a demo file modified to
its target version; `SMART` = source-aware binary delta. Many entries appear twice -- once
under the top-level `Data/...` install copy and once under `release/Data/...` (the live
client working tree); both must be present.

Total: 589 files (1 SMART, 405 ADD, 183 PATCH).

### Client executable (source-aware delta)
- **`release/client.exe`** (SMART) -- the game client itself. Freya EnB Emulator's build adds the
  master-server connection logic and the full guild/social/GM command set. Shipped as a
  binary delta, never whole. **Required** to connect to a Freya EnB Emulator server.
  If you check the `reference/client.exe/*.xd3` files, these are the deltas you need to apply to
  existing `client.exe` binaries (that match the hash on the filename preceeding the xd3 extension)
  to produce the intended client.exe.
